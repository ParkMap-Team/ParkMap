# detection/notebooks

`ParkMap_YOLO_Training_Evaluation.ipynb`: optional Google Colab version of detector training and evaluation for a
private Drive copy of the dataset. Settings are in its Configuration cell (Colab cannot read `../config.yaml`).
Training, test evaluation and image previews are off by default.

Clear all outputs and execution counts before committing. The notebook's helper functions are tested by
[`../tests/test_notebook.py`](../tests/README.md). Step-by-step use: [../README.md](../README.md#optional-colab-notebook).
