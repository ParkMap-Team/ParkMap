# Motorcycle settings in LIFF

The settings tile opens /settings in LIFF. Users must choose one of twelve models or other before accessing a map. Existing saved preferences are retained per verified LINE account (same Provider). A save returns to the map; reopening settings allows changes. Each successful explicit save also attempts an OA text confirmation via the official Python LINE SDK. No chat settings menu is sent.

See ADR 0019. The lightweight parkmap-bot resource now serves the account-preferences API at /api/line/preferences; its old webhook returns 404. Keep DATABASE_URL and set LINE_LOGIN_CHANNEL_ID=2011859796. Startup keeps its independent parkmap_line migration history. LINE_CHANNEL_ACCESS_TOKEN is required in this process runtime for push confirmations. LINE_CHANNEL_SECRET and Use webhook are not needed. Users should add the ParkMap OA as a friend and not block it. LINE Login and Messaging API must share the same Provider. A provider failure or timeout never rolls back the saved preference; notification_status reports accepted, failed, or not_configured. Accepted means LINE accepted the request, not proof of device delivery. Each explicit save attempts one push with a UUID retry key; reads/polls never send a notification, and there is no background retry queue.

LIFF runtime needs PARKMAP_SETTINGS_URL pointing to that internal resource on port 8000 and PARKMAP_PUBLIC_ORIGIN=https://app.parkmap.dev. NEXT_PUBLIC_LIFF_ID stays unchanged. The LIFF app must have openid enabled. Deploy settings service and LIFF, verify health and anonymous map/state/photo requests are refused, then publish the five URI rich menu. Preserve the previous menu for rollback. Disable Use webhook in LINE Console after rollout; the retired endpoint accepts no events regardless of that switch.

Verify in LINE on a phone: first-time account is prompted, cannot bypass with a direct map link, can save and view the map, and can reopen settings. A second account must have its own preference. Failed verification or storage must not unlock a map. Help and mobile-camera pairing remain independent. No database rows are dropped as part of this change.
