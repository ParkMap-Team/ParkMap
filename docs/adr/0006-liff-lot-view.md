# Build a bounded and resilient LIFF lot view

Status: accepted, 2026-10-03. The LIFF app will bundle one generic motorcycle GLB in the repository with a clearly documented license such as CC0 or Apache-2.0 and render it as an instanced detection proxy; it communicates position, long-axis direction, and approximate size only, not reconstructed vehicle geometry. The 3D view starts at an overview preset and offers an entrance-view preset, bounded orbit and zoom, and a reset control, without unrestricted free-fly navigation. When WebGL is unavailable it immediately uses a top-down 2D renderer, and when the 3D scene has not finished loading within 5 seconds it falls back to 2D; a manual 2D/3D switch remains available when both renderers are usable. Both renderers preserve the API status mapping: `AVAILABLE` green, `ALMOST_AVAILABLE` yellow, occupied evidence red, `UNKNOWN` a distinct non-availability colour, and `UNMONITORED` a separate dark treatment, with a legend. This keeps the lot usable on low-end phones at the cost of maintaining a second renderer and accepting less camera freedom.
