# Build a resilient LIFF lot view

Status: accepted, 2026-10-03. The LIFF app will bundle one generic motorcycle GLB model in the repository with a clearly documented license such as CC0 or Apache-2.0 and render it as an instanced detection proxy; it communicates position, long-axis direction, and approximate size only, not reconstructed vehicle geometry. The 3D view starts at an elevated overview preset that frames the whole lot and offers an entrance-view preset looking into the lot from its entrance, bounded orbit and zoom around the lot, a reset control that returns to the overview, and an optional free-fly mode for arbitrary navigation through the static lot model. Moving the virtual camera never creates new observation evidence or turns occluded, stale, `UNKNOWN`, or `UNMONITORED` ground into available space. When WebGL is unavailable the app immediately uses a top-down 2D renderer, and when the 3D scene has not finished loading within 10 seconds it falls back to 2D; a manual 2D/3D switch remains available when both renderers are usable. Both renderers preserve the API status mapping: `AVAILABLE` green, `ALMOST_AVAILABLE` yellow, occupied evidence red, `UNKNOWN` a distinct non-availability colour, and `UNMONITORED` a separate dark treatment, with a legend. This keeps the lot usable on low-end phones at the cost of maintaining a second renderer and more complex camera controls.
